# AI-Powered Diving Safety Assistant

A constraint-grounded LLM reasoning system for recreational diving safety.

## Features

- Natural language dive plan parsing
- Risk scoring (depth, time, current, temperature)
- Rule-based + semantic verification
- Safe recommendation generation
- Deterministic fallback (no API required)

## Demo

Example input:

> I am a beginner and want to dive 32 meters for 40 minutes in 14°C water with strong current.

## Tech Stack

- Python
- Gradio
- LLM (optional)
- Rule-based safety verification

## Disclaimer

This is an educational prototype only. It does not replace certified dive training or dive planning tools.
